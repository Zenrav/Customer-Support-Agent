# AI Customer Support Agent

An intelligent, multi-agent customer support system built to automate query resolution, route ticket requests, and manage customer interactions.

## 🚀 Features

- **Automated Query Handling:** Resolves FAQs and common user requests using LLMs.
- **Agentic Routing:** Evaluates complex inquiries and routes them to specialized agents or human operators.
- **Context Awareness:** Maintains session state and user interaction history across multi-turn conversations.
- **Modular Design:** Simple to extend with custom API tools, database connectors, or internal KB integrations.
